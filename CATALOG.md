# Folio adapter catalog

Add-ons for [Folio](https://github.com/solacecasino/folio). Pick one, download the zip for your
computer, then drop it on the Folio window, or choose **Folio → Adapters… → Add Adapter…**.
Folio shows what an adapter can do and asks you before it first runs.

**Made one?** [List it here](catalog/README.md): it's a two-line file. Start from the [template](https://github.com/solacecasino/folio-adapter-template) to get downloads for every platform.

## Collaboration

### Folio Link

Edit a document together, live, over an encrypted direct link. No accounts.
