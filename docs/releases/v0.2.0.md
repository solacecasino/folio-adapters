The adapters now come for **macOS, Windows and Linux**, for [Folio 0.6](https://github.com/solacecasino/folio/releases/tag/v0.6.0).

Pick the zip for your computer. In Folio choose **Folio → Adapters…** (Cmd+Shift+A, or Ctrl+Shift+A), then **Add Adapter…**, and pick it.

| Adapter | macOS (Apple Silicon) | Windows (64-bit) | Linux (x86-64) |
|---|---|---|---|
| **PDF Export**: File → Export as PDF | `pdf-export-0.2.0-macos-arm64.zip` | `pdf-export-0.2.0-windows-x64.zip` | `pdf-export-0.2.0-linux-x64.zip` |
| **Folio Link**: live co-editing with people you invite, across any of the three | `folio-link-0.2.0-macos-arm64.zip` | `folio-link-0.2.0-windows-x64.zip` | `folio-link-0.2.0-linux-x64.zip` |
| **Writing Tools**: word goal, date, stats | `writing-tools-0.2.0.zip` (all platforms, needs Python 3) | | |

## Changes

- Builds for Windows and Linux, made and tested by GitHub Actions on each platform.
- Folio Link keeps its identity key and settings in Folio's config folder on every platform, and uses your account name on Windows and Linux.
- `scripts/build.py` builds the adapters for whatever computer you run it on.
