For [Folio 1.0.2](https://github.com/solacecasino/folio/releases/tag/v1.0.2), which draws and prints lists and links.

- **New: Rich Content 0.1.** Bulleted and numbered lists, and links, from the Format menu: Bulleted List (Cmd+Shift+8), Numbered List (Cmd+Shift+7), Add Link… (Cmd+K), Remove Link. In Folio, Tab and Shift+Tab change a list item's level and Cmd/Ctrl-click opens a link.
- **Folio Link 0.3.1:** lists and links stay in sync while you edit together (before, they'd be dropped).
- **PDF Export 0.2.2:** links are clickable in the PDF.

Install: download the zip for your computer and drop it on Folio's window.
